## 为什么写博客

我是软件工程专业的学生，未来的程序员。写博客对我而言只有两个朴素的目的：**沉淀技术**，和**记录生活**。

技术需要输出才能内化。很多知识「看懂了」和「能讲清楚」之间，隔着一条需要反复练习的鸿沟。把踩过的坑、学到的东西写下来，就是给自己建立一座可随时回看的弹药库。

生活同样值得记录。篮球、健身、音乐，这些看似与代码无关的东西，其实都在教我一件事：**持续投入，等待弧线抵达最高点**。

## 一个关于「弧线」的隐喻

投篮的抛物线，和写代码的成长曲线，惊人地相似：

- 出手要稳，姿势要正 —— 基础要扎实；
- 球在空中有起伏，不是直线 —— 学习有平台期；
- 但只要重复正确动作，球总会进 —— 刻意练习终有回报。

所以我把这个博客命名为 **ARC·CODE** —— 弧线与代码。

## 技术选型

这个博客用 React + Vite + TypeScript 搭建，Markdown 写作，部署在 GitHub Pages 上。选择它的理由很简单：

| 维度 | 选择 |
| --- | --- |
| 框架 | React（现代前端框架） |
| 内容 | Markdown + frontmatter |
| 艺术 | p5.js 生成动态背景 |
| 部署 | GitHub Pages（免费静态托管） |

更多细节，可以看我写的《从零搭建一个部署到 GitHub Pages 的 React 博客》。
