# ARC·CODE 博客

一个个人**技术 + 生活**博客：用 React 分享技术知识、记录生活热爱（篮球 / 健身 / 音乐），支持图片展示，部署在 GitHub Pages。

- 线上地址：<https://yujintao0927.github.io/>
- 技术栈：React 18 · Vite 5 · TypeScript · React Router（HashRouter）· react-markdown · p5.js · highlight.js

## 快速开始

```bash
npm install
npm run dev       # 本地开发 http://localhost:5173
npm run build     # 构建到 dist/
npm run preview   # 本地预览构建产物
```
